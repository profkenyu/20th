 TERRA INCOGNITA — 지도 이전의 세 표면
 20회 개인전 · 작품 관람법 및 조작 방법
════════════════════════════════════════════════════════════════════

■ 작품의 시작

  · 시작 버튼              : 서문이 나타난 뒤 1.6초부터 활성화됩니다.
                             버튼을 누르거나 Enter/Space를 누르면 시작 순서가
                             열립니다. 서문이 2.7초 동안 사라진 뒤 로버의
                             와이어프레임 구성이 시작됩니다. 아무 조작이
                             없으면 7.2초 뒤 자동으로 진행됩니다.
  · OBSERVER               : 기본 관람 모드입니다. 로버가 세 행성의 임무를
                             스스로 수행하고 카메라가 장면을 연출합니다.
  · EXPLORER               : 관람객이 직접 조향하는 모드입니다. 직접 조작
                             뒤 12초간 입력이 없으면 OBSERVER로 돌아갑니다.
  · UNIVERSE #XXXXXX       : 세션 최초 진입 때 생성되는 우주 좌표입니다.
                             작품이 처음으로 복귀해도 같은 세션 안에서는
                             좌표가 유지됩니다.
  · 자동 복귀              : 8분 동안 입력이 없으면 다음 관람객을 위해
                             서문과 PLANET 01의 시작 지점으로 돌아갑니다.
  · ARCHIVAL TERMINAL      : 연산 자원이 낮거나 지속적인 과부하가 감지되면
                             녹색 형광체의 30Hz 기록 모드로 전환됩니다.
                             오류가 아니라 작품의 저연산 관람 상태입니다.

■ 데스크톱 조작

  · W / A / S / D          : 전진·후진·좌우 조향. 누르는 순간 EXPLORER로
                             전환됩니다. 방향키도 같은 방식으로 작동합니다.
  · Shift                  : EXPLORER에서 누르고 있는 동안 고속 주행합니다.
  · Space                  : 직접 조작을 끝내고 OBSERVER 자율 탐사로 즉시
                             돌아갑니다.
  · C                      : 현재 임무가 허용하는 시네마틱 숏을 순환합니다.
                             스캔·격납·비행 중에는 작품의 필수 숏이 우선합니다.
  · L                      : 로버의 전조등을 켜거나 끕니다. 전력 셀이
                             고갈되면 전조등도 함께 꺼집니다.
  · H                      : 엔지니어링 HUD를 화면에 고정하거나 해제합니다.
                             평상시에는 화면 왼쪽 끝에 포인터를 대면 잠시
                             나타납니다.
  · M                      : 앰비언트 사운드를 음소거하거나 복원합니다.

■ 모바일 조작

  · 시작                   : 로버 구성 시작 버튼을 탭하면 기울기 센서 권한을
                             요청합니다. 권한을 거절해도 작품은 중단되지 않고
                             드래그 조향과 자율 관람을 사용할 수 있습니다.
  · ENABLE TILT            : 허용 후 기기를 좌우로 기울이면 조향합니다.
                             기기를 세우면 정지하고, 앞으로 눕히면 주행합니다.
  · DRAG STEER             : 하단 중앙 영역을 좌우로 드래그해 조향합니다.
                             센서가 없거나 거절된 기기의 기본 대체 조작입니다.
  · OBSERVER / EXPLORER    : 하단 우측 버튼을 탭하면 직접 탐사로 들어갑니다.
                             탐사 중에는 같은 버튼으로 정지·재개합니다.
  · 사운드 상태 버튼       : TAP FOR SOUND는 시작 필요, SOUND · ON은 재생 중,
                             RESUME SOUND는 복구 필요, SOUND · OFF는 꺼짐입니다.
                             우상단 버튼을 탭해 시작·복구·켜기·끄기를 실행합니다.
  · 화면 회전              : 세로·가로 회전 뒤 기울기 기준을 자동으로 다시
                             맞춥니다. 가로 화면에서는 시작 버튼이 본문과
                             겹치지 않도록 별도 위치에 표시됩니다.

■ 사운드 안내

  작품은 마이크를 사용하지 않습니다. 시작 버튼이나 Enter/Space처럼 관람객의
  실제 입력이 있을 때 Web Audio 기반 핑크 노이즈와 저주파 드론의 재생을
  시도합니다. 7.2초 자동 진행만으로는 브라우저 정책상 소리가 시작되지 않을
  수 있으므로 TAP FOR SOUND를 한 번 탭하세요.

  SOUND · ON은 오디오 엔진이 실제 재생 상태임을 뜻합니다. 아이폰에서 앱
  전환·화면 잠금 뒤 RESUME SOUND가 표시되면 버튼을 다시 탭하세요. 로버의
  전력이 낮아지면 음량도 함께 줄어듭니다. 기기의 무음 모드·출력 경로·전시장
  음량은 브라우저 밖의 상태이므로 전시 시작 전에 실제 기기에서 확인합니다.

 조작 : OBSERVER로 전체 임무를 먼저 지켜보는 것을 권합니다. 로버를 직접
        움직이고 싶을 때만 WASD/방향키 또는 모바일 기울기·드래그를
        사용하고, Space나 12초 무입력으로 다시 자율 관람에 맡겨 보세요.

 관람 : 작품은 세 표면을 하나의 기억 흐름으로 연결합니다.

        · PLANET 01 / MATTER
          로버가 여덟 물질 서명을 찾을 때마다 착륙선의 구조가 한 부분씩
          복원됩니다. 바퀴의 독립 서스펜션, 지표에 남는 두 줄의 흔적,
          경사에서 흔들리는 전조등과 태양광 전력을 함께 보세요.

        · PLANET 02 / WATER
          복원된 착륙선이 로버를 격납하고 다음 행성으로 이동합니다.
          두 번째 표면에서 확인되는 물은 웅덩이가 아니라 수화 규산염과
          지하 공극 얼음의 관측 신호입니다.

        · PLANET 03 / MEMORY
          첫 행성의 여덟 물질 위상과 두 번째 행성의 수분 기록이 겹쳐
          세 개의 지질 기억 결절을 만듭니다. 앞선 두 세계의 증거가
          모아레형 간섭 구조로 다시 나타나는 과정을 지켜보세요.

        로버와 착륙선이 입자로 분해·압축·재조립되는 행성 간 통과 장면은
        세 임무를 잇는 중심 악장입니다. 서두르지 말고 한 번의 전체 순환을
        처음부터 끝까지 감상하는 것을 권합니다.
