TERRA INCOGNITA
작품 줄거리 · 행성별 특징 · 임무 · 기기별 조작법
20회 개인전 · Kim Gunwoo


1. 작품 개요

Terra Incognita는 통신이 끊긴 자율 로버가 세 개의 미지 행성을 통과하며
착륙선과 생존 자원, 그리고 서로 다른 행성의 관측 기억을 보존하는 실시간 작품이다.

관람자는 기본적으로 로버를 멀리서 지켜보는 관측자(OBSERVER)다. 로버는 스스로
목표를 찾고, 지형에 멈춰 관측하며, 임무가 끝나면 착륙선으로 돌아간다. 관람자가
직접 조작하면 탐사자(EXPLORER)가 되어 로버의 경로를 잠시 바꿀 수 있다. 조작이
12초간 없으면 작품은 관측자 상태와 자율 항로로 돌아간다.

작품의 핵심은 수집 아이콘이 아니라 물리적 징후의 관측이다. 지면의 반사, 흡수
스펙트럼, 냉각 음영, 입자 밀도와 간섭 무늬가 로버의 정지와 측정을 통해 상태로
변환된다. 임무 완료 뒤 로버는 착륙선 내부에 격납되고, 착륙선은 다음 행성으로
이동한다. 마지막 행성에서는 앞선 두 행성의 기록이 세 개의 지질 기억 결절로
나타난 뒤 소멸하며 작품이 다시 처음으로 돌아간다.


2. 전체 서사와 시간 흐름

01  설계도 개방
    모니터 노이즈 속에서 로버와 착륙선 설계도가 순차적으로 드러난다.

02  제목과 START
    제목 화면에서 START를 누르면 검은 화면과 수신기 복원 과정을 거쳐 진입한다.
    입력이 없으면 8초 뒤 자동으로 작품이 시작된다.

03  PLANET 01 · SHEAR WORLD
    로버가 구조재 5종과 자원 3계통을 순서대로 관측한다.
    첫 5개는 착륙선의 외부 구조를 실제로 완성한다.
    마지막 3개는 N₂, H₂O, EtOH 자원 게이지를 상승시킨다.

04  완성 사건
    구조재 5/5와 자원 3/3이 모두 충족되면 약 5.4초의 등록 장면이 열린다.
    외부 구조가 하나의 물질 상태로 고정되고 세 자원 바가 100%에 도달한다.

05  격납과 이동
    착륙선 램프가 열리고 로버는 실제 바퀴 접지로 내부에 진입한다.
    격납 위치가 고정된 뒤 램프가 닫히고 착륙선이 이륙한다.

06  PLANET 02 · YARDANG FIELD
    로버가 재배치되어 단 하나의 수분 후보 지점을 추적한다.
    수분 관측이 끝나면 다시 격납되어 세 번째 행성으로 이동한다.

07  PLANET 03 · JOINTED GRANITE
    PLANET 01의 8개 회수 서명과 PLANET 02의 수분 스펙트럼이 결합되어
    세 개의 지질 기억 결절을 만든다. 로버가 세 결절을 모두 관측하면 기록은
    하나의 간섭장으로 정렬된 뒤 사라지고 작품은 자동으로 초기화된다.


3. PLANET 01 · SHEAR WORLD

특징
    Schwarzschild 유효 퍼텐셜이 행성 지형의 장벽, 골, 접근 불가능한 중심을 만든다.
    붉은 전단 광물층과 공기가 없는 암흑 지표가 중심 질량 주변에 배열된다.
    각운동량 장벽은 장식물이 아니라 로버의 경로와 견인을 실제로 제한한다.

임무
    여덟 관측 지점을 순서대로 통과한다.

    외부 구조재 5종
      1) FE–NI ALLOY          · FOUNDATION
      2) SILICATE CERAMIC     · LOAD PATHS
      3) CARBON COMPOSITE     · SERVICE / PRESSURE
      4) CONDUCTIVE LATTICE   · TRANSFER / VISOR
      5) RARE-EARTH CERAMIC   · SENSOR / SIGNAL

    자원 게이지 3계통
      6) N₂ RESERVE           · ATMOSPHERE BASE
      7) H₂O RESERVE          · O₂ / POTABLE BASE
      8) ALCOHOL · C₂H₅OH     · CHEMICAL FEEDSTOCK

게이지 표현
    우상단 녹색 형광체 모니터의 하단에는 구조 상태 5칸과 자원 게이지 3개가 있다.
    자원을 획득하면 숫자 메타게이지가 000%에서 100%로 상승하고, 같은 시간에
    바게이지가 왼쪽에서 오른쪽으로 채워진다. 마지막 완성 등록 화면에서도
    구조재 5칸과 자원 바 3개가 서로 다른 상태로 표시된다.

획득 방법
    목표 지점 가까이 접근한 뒤 속도를 약 0.12 m/s 이하로 낮춘다. 약 3.6초간
    안정적으로 머물면 관측이 확정되고, 전체 시각 사건은 약 5.4초 뒤 끝난다.
    자율 모드에서는 로버가 스스로 감속하고 정지한다. 직접 조작 중에는 목표에서
    이탈하거나 빠르게 움직이면 스캔이 취소되므로 다시 접근해야 한다.


4. PLANET 02 · YARDANG FIELD

특징
    한 방향의 바람이 만든 야르당 능선, 소결된 지각, 낮은 열관성, 하전된 규산염
    이동 흔적이 있는 건조 행성이다. 지표의 물 웅덩이를 표현하지 않는다.

임무
    음영진 다공성 지층의 수분 등가 수소를 확인한다. 증거는 낮은 열 반응,
    1.4 / 1.9 / 2.9 µm 흡수대, 수화 규산염의 어두운 중심, 입자 밀도 변화다.

획득 방법
    후보 중심에서 약 3.8 m 안으로 접근하고 속도를 0.12 m/s 이하로 유지한다.
    약 4.2초 동안 위치를 유지하면 H₂O 관측이 확정된다. 이후 격납과 이동은
    자동으로 진행되며 관람자 입력은 잠긴다.


5. PLANET 03 · JOINTED GRANITE

특징
    오래된 화강암 지각, 박리 돔, 두 방향의 냉각 절리, 석영·장석·운모 반사가
    나타난다. 앞선 행성의 기록이 두 고리 계열과 입자 밀도의 간섭으로 드러난다.

임무
    세 개의 CONCORDANCE NODE를 순서대로 관측한다. 각 결절은 물질 위상,
    수분 위상, 두 기록의 일치도를 서로 다른 간섭 무늬로 보여준다.

획득 방법
    현재 결절에서 약 4.2 m 안으로 접근하고 속도를 0.12 m/s 이하로 유지한다.
    약 4.2초 뒤 기록이 고정된다. 세 번째 기록이 끝나면 최종 장면과 자동 복귀가
    시작되므로 별도의 버튼 조작은 필요하지 않다.


6. 데스크톱 · 노트북 · 프로젝터 조작법

START 화면
    START 클릭 또는 Enter / Space    작품 시작
    입력 없음                         제목이 열린 뒤 8초 후 자동 시작

관람 모드
    기본 상태는 OBSERVER · AUTONOMOUS다. 카메라와 자율 항로가 작품의 편집을
    담당한다. 화면 왼쪽 가장자리에 포인터를 두면 상세 진단 HUD가 잠시 나타난다.

직접 탐사
    W / A / S / D 또는 방향키         전진·후진·좌우 조향, EXPLORER 진입
    Shift                              직접 주행 중 고속 이동
    Space                              OBSERVER 복귀 및 자율 탐사 재개
    C                                  허용된 카메라 숏 순환
                                       (광각, 후면, 8mm 로버 시점,
                                        근접, 착륙선 망원 중 상황별 선택)
    L                                  로버 전조등 켜기 / 끄기
    H                                  상세 엔지니어링 HUD 고정 / 해제
    M                                  사운드 음소거 / 재생 / 중단 복구

주의
    스캔, 격납, 이륙, 착륙, 최종 장면에서는 직접 조작과 카메라 전환이 잠긴다.
    수동 주행을 멈추고 12초가 지나면 OBSERVER와 자율 항로로 자동 복귀한다.


7. 스마트폰 · 태블릿 조작법

시작
    모바일 START를 누르면 작품 시작, 사운드 활성화, 기울기 센서 권한 요청이
    같은 사용자 동작에서 진행된다. 센서 권한을 허용하지 않아도 작품은 실행되며
    DRAG STEER 방식으로 조작할 수 있다.

직접 탐사 전환
    우측 하단 상태 버튼을 처음 탭하면 OBSERVER에서 EXPLORER로 전환된다.
    EXPLORER에서 다시 탭하면 HOLD, 한 번 더 탭하면 탐사를 재개한다.
    상태 버튼을 0.7초 이상 길게 누르면 기울기 중립값을 다시 보정한다.

기울기 조향
    기기를 좌우로 기울이면 해당 방향으로 조향한다.
    기기를 세우면 TILT PARK 상태로 정지하고, 앞으로 눕히면 다시 출발한다.
    기기를 화면 회전한 뒤에는 잠시 수평을 유지해 자동 재보정을 완료한다.

드래그 조향
    DRAG STEER 영역을 누른 상태로 좌우 드래그한다. 손을 떼면 조향 입력은 0이
    되지만 이미 선택된 로버 진행 방향은 유지된다. 센서가 거절되거나 지원되지
    않는 기기에서도 사용할 수 있다.

사운드
    우상단 TAP FOR SOUND / SOUND ON / RESUME SOUND / SOUND OFF 버튼을 사용한다.
    iOS가 백그라운드 전환 뒤 오디오를 중단한 경우 RESUME SOUND를 탭한다.

모바일 자동 관리
    태양광 패널과 전조등은 자동으로 관리된다. 스캔·격납·비행 구간에는 모든
    모바일 주행 입력이 잠기며, 완료 뒤 자동으로 다시 활성화된다.


8. 전시 운영자용 점검

배포 파일
    dist/TERRA_INCOGNITA.html
    외부 네트워크 없이 실행되는 단일 HTML이다.

권장 실행
    최신 WebGPU 지원 Chrome 계열 브라우저와 전용 또는 통합 GPU를 사용한다.
    프로젝터 연결 뒤 전체 화면, 화면 비율, 절전, 알림, 오디오 출력 장치를 확인한다.

성능 단계
    HIGH  설치용 데스크톱 GPU: 높은 내부 해상도와 전체 광학 후처리
    MID   노트북·태블릿: 중간 DPR과 축소된 입자·후처리 비용
    LOW   스마트폰·저성능 GPU: 낮은 내부 해상도와 녹색 형광체 기록 화면

    세 단계 모두 5개 구조재, 3개 자원 게이지, 세 행성 임무와 최종 사건을 동일하게
    유지한다. 계산 장식보다 구조적 상태를 먼저 보존한다.

운영 점검 단축키
    =                                  PLANET 01의 5+3 상태를 동시 획득
                                       (전시 전 완성·격납 시퀀스 점검용)
    H                                  엔지니어링 HUD 표시
    M                                  오디오 상태 점검

실기기 확인
    외부 링크 첫 진입과 새로고침을 각각 확인한다. iPhone / iPad에서는 주소창 변화,
    세로·가로 회전, 안전영역, START 버튼, 사운드 복귀, 기울기 권한과 드래그 대체
    조작을 점검한다. 브라우저의 이전 페이지 캐시에서 돌아온 경우에도 작품 시간이
    숨겨진 동안 진행되지 않고 정상 위치에서 재개되는지 확인한다.


9. 과학적 정확성 · 수치 근사 · 예술적 해석

과학적으로 근거가 있는 부분
    Schwarzschild 유효 퍼텐셜의 극값과 각운동량 장벽, 태양광 전력 수지,
    8개 바퀴 접지·현가·경사에 따른 견인, 수분 흡수대와 열 관성 관측을 사용한다.
    N₂는 산소 원료가 아니라 대기 완충·압력 유지용 기반이다. H₂O는 전기분해 시
    산소 원료이자 식수 기반이며, EtOH는 연료·용매·화학 원료가 될 수 있다.

실시간 수치 근사
    유효 퍼텐셜의 높이 비율을 전시 가능한 미터 규모 지형으로 확대하며, CPU 지형
    복제본으로 바퀴 접지와 스캔 높이를 계산한다. 제한된 입자와 고리, 이산 관측
    지점을 사용해 연속 물리계를 실시간으로 근사한다.

예술적 해석
    하나의 물질 서명이 착륙선 구조 전체를 물질화하는 과정, 행성 간 이동의 좌표
    압축, 서로 다른 행성 기록이 화강암 위의 기억 결절로 나타나는 과정은 서사를
    위한 변환이다. 실제 우주선 제작 질량이나 완전한 생명 유지 공정으로 주장하지
    않는다.


10. 작품의 대표 사건

대표 사건은 더 밝아지는 폭발이 아니라 상태의 전환이다. 분리되어 있던 구조재
5종과 자원 3계통이 하나의 완성 상태로 정렬되고, 로버가 어둠 속 착륙선 내부로
사라진 뒤 착륙선 전체가 표면 기준에서 분리된다. 관람자가 조작하던 기계가 더 이상
인터페이스가 아니라 운반되는 질량이 되는 순간이 작품의 기억점이다.
